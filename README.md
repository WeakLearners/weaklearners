# weaklearners

A weak learner is a model that is barely better than a coin flip. Stack enough of them and they get strong. Most of my ideas start out as weak learners too. The trick is keeping score.

I'm Sean. I'm finishing an MS in Computer Science. I build software that runs unattended, and I care most about the point where it stops and asks first.

I'm looking for AI and LLM application engineering work, including internships.

## Public work

**[overwatch-tracker](https://github.com/weaklearners/overwatch-tracker)**
Everyone has a theory about why they lose. I had plenty. Then I started writing every match down.
A React, Express, TypeScript and SQLite app with 3,639 matches logged over 22 months. It has an LLM pre-match advisor on Claude Haiku, cached for 7 days. Every pattern has to survive multiple-comparison correction before the app calls it a finding. Across 32 maps, none did.

**[nfl-props](https://github.com/weaklearners/nfl-props)**
It found an edge. The edge was a bug.
A Python system that ranked NFL player props by how reliably they hit. A test across 777 past bets said strong track records won about 3 in 4. The lookup was scoring the wrong line. With the fix, the strongest third of bets won 61.0% and the weakest third won 61.9%. The README says so at the top.

## Beliefs that died

I keep a list. A belief goes on it when a number kills it.

- "Noon is my one real bad hour." Still bad. Not proven. Test 12 hours and one will look awful by luck.
- "A strong track record means the next bet hits." It does not. That result came from a bug.
